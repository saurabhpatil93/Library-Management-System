# 📚 Smart Library Management System

A modern full-stack Library Management System developed using Flask, SQLite, HTML, and CSS.  
This project provides an interactive dashboard for managing books, members, issued books, returned books, and fine records with a professional user interface.

---

# 🚀 Features

## 🔐 Authentication System
- User Registration
- User Login
- Logout Functionality
- Session Management

## 📚 Book Management
- Add New Books
- Delete Books
- View Book Database
- Author & Genre Support
- Book Availability Tracking

## 👨‍🎓 Member Management
- Register Members
- View Member Records
- Manage User Accounts

## 📖 Issue & Return System
- Issue Books to Members
- Return Book Management
- Issue Date & Due Date Tracking
- Return Status Management

## 💰 Fine Calculation System
- Automatic Fine Calculation
- ₹10 Fine Per Day Delay
- Paid / Unpaid Fine Status
- Fine Record Database

## 📊 Dashboard Analytics
- Added Books Count
- Members Count
- Issued Books Count
- Returned Books Count
- Fine Records Count
- Interactive Tables

## 🎨 Modern User Interface
- Responsive Design
- Animated Login & Register Pages
- Dashboard Cards
- Styled Tables
- Hover Effects
- Mobile Friendly UI
